# F22 小飞机：教学资料与比赛工程

现在分成两个独立文件夹，各自有源码、PlatformIO配置、文档、CSV与遥控器程序：

| 目录 | 用途 | 从这里打开 |
|---|---|---|
| `01_教学demo/` | 七课demo、教程、手册、实验、测试、原采集数据 | [教学目录说明](01_教学demo/README.md) / [一份教学总讲义](01_教学demo/教学总讲义.md) |
| `02_比赛工程/` | 后续比赛开发使用的独立工程，真实传感器与无线任务控制 | [比赛工程说明](02_比赛工程/README.md) |

带给队员的单文件包：[教学资料.zip](教学资料.zip)。包含教学目录的源码、全部教程、手册、CSV、已编译飞控BIN与遥控器HEX，不含PlatformIO缓存。

在对应文件夹运行命令，避免把某课固件与比赛入口混淆：

```bash
cd "/data/Downloads/f22_hal_demos/01_教学demo"
bash scripts/check_demos.sh
```

```bash
cd "/data/Downloads/f22_hal_demos/02_比赛工程"
pio run -e contest_hover
```

比赛目录是以后持续开发的比赛工程入口，当前电机输出关闭；模块到货、坐标/光流标定、电机布局、供电与实机控制验证尚未完成，不能称为已经可以上场飞行。新工程没有自动解锁的真飞开关。本次整理不烧录、不运行电机。

原来根目录的`vofa+.csv`与长文件名比赛PDF保留兼容链接；实际数据和规则手册集中到教学文件夹中，内容未改。教学工程内保留各课独立README供日后更新，总讲义可由脚本重新生成。
