# 第 5 课：VL53L1X 测距

目标：用激光飞行时间测量传感器到地面的距离，区分“芯片识别成功”“一次测量有效”“数据仍然新鲜”。本课使用已购买的正点原子 ATK-PMW3901 **4m** 模块中的 VL53L1X，不能换成 2m 版 VL53L0X 驱动。

前置：第 1 课 VOFA、I²C 地址与 7/8 位地址区别。先读 [模块转接接线](../../../docs/MODULE_WIRING.md)，模块原手册保存在 [参考目录](../../../docs/references/README.md)。算法入口是 `src/sensors/tof.c`，F22 硬件适配在 `src/sensors/f22_sensor_bus.c`，高度滤波在 `src/flight/observation.c`。

```bash
pio run -e demo05_tof
pio run -e demo05_tof -t upload
```

VOFA 用 JustFloat / 115200 / 8N1 / DTR=1 / RTS=0；导入 [vofa.csv](vofa.csv)，12 列，初始全 0。本课约 25 Hz 发帧，测距配置为长距离模式、33 ms 时间预算、40 ms 测量间隔。发帧与新测量频率可能不同，`fresh_sample` 表示本轮真的读到了新结果。

| CH | 名称 | 含义 |
|---|---|---|
| 0 / 1 | distance_mm / distance_m | 原始距离毫米 / 有效距离米 |
| 2 / 3 | height_level_m / vz_level_mps | 假设模块水平时的低通距离与向上速度 |
| 4 / 5 | tof_present / tof_valid | 初始化成功 / 测量通过状态、量程和时效检查 |
| 6 | tof_raw_status | 原始芯片状态；9 才是本例接受的有效值，未映射成 ST API 的 0 |
| 7 | tof_id | 型号 ID：0xEACC，十进制 60108 |
| 8 / 9 | sample_age_ms / fresh_sample | 数据年龄；还没有结果时 -1 / 本轮新结果标志 |
| 10 / 11 | tof_errors / actual_pwm | 当前初始化周期内通信/超时计数 / 恒 0 |

实验：模块水平向下，对准有纹理的平地，用尺子设置 0.2、0.5、0.8 m，各静置 10 s；记录均值、波动范围、有效率和更新间隔。遮住测距窗口、远离量程后观察 `tof_valid=0`；有效距离/滤波高度显示 NaN，而不是伪造零高度。数据超过 150 ms 不再有效；超过 500 ms 没新结果则重新初始化，重试间隔约 2 s。

原始距离从**传感器测量平面**算起，不是飞机机身中心。倾斜时读到斜距，本课没有 IMU，因此 CH2/3 只适合水平台架；第 7 课用姿态估计做 `distance*cos(roll)*cos(pitch)` 投影。传感器安装偏移、覆盖片串扰与零点偏差仍需尺子实验校准。速度来自低通高度的差分，响应有延迟；尚未与惯性加速度融合。

常见错误：把 0x29 写成 HAL 传输参数而不左移；用 8 位寄存器地址（该芯片要求 16 位）；没接模块使能造成内部地悬空；只看旧距离而忽略有效位；以为 4m 是在任意强光下都保证测准。解决方法先对照接线和状态，再用尺子复测。

练习：为什么距离增长对应向上速度？为什么遮挡不能被当作已落地？用主机测试解释通信失败与非有效测距状态的不同路径。
