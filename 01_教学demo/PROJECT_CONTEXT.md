# 项目上下文

类型：嵌入式代码与队内教学资料。受众默认具备 C 基础，尚未系统学习无人机控制。目标是让队员独立运行、解释、验证每课，最终完成比赛的小飞机悬停。

## 已知事实

- UAV-F22，STM32F103RCT6，8 MHz HSE / 72 MHz 系统时钟，HAL + PlatformIO。
- USB CH340 与 E49 共用 USART1。VOFA 使用 115200；现有 TLE100 例程使用 9600。遥控日志放 UART4 / JP14，避免混发到无线模块。
- MPU6050 与 SPL06 能读取。当前板的 QMC5883L 在正确 7 位地址 0x0D 没有应答；记录为磁力计通信故障，芯片本体故障尚不能独立确认。
- SPL06 换算的相对高度有噪声和漂移，CH19 仅作诊断，不作为低空离地高度输入。
- 已购正点原子 ATK-PMW3901 4m，集成 PMW3901(SPI)与VL53L1X(I²C)；ToF、光流尚未安装；遥控器烧录工具待到货。第 2 课可先测试纯解析逻辑，实机射频链路待验证。
- 旋翼输出可用 M1~M4、M6/M7；M5 是减速电机口。实际机架的电机数量、位置、旋向与板口对应尚未确认。
- M6/M7 与 I2C1 共用 PB6/PB7；新增 I2C 测距优先按实际模块电气要求接 I2C2。
- CH340 有间歇重枚举问题；烧录成功与遥测运行成功分别记录。当前目录的 Git 元数据不可用。

## 固定约定

每课独立环境、独立 main、独立 README；算法模块放 `src/flight`，不依赖 HAL。默认例程不驱动电机。软件模型、主机测试、实机证据分别标注，不能互相代替。

未来实机飞行前必须确认坐标轴、布局、PWM 波形、遥控心跳、传感器时效与供电。第 4 课的模型参数和虚拟电机顺序不代表这些已完成。

当前交付七课、遥控新旧接收环境、单电机台架变体和独立TLE100发射端。原厂单字符无心跳；新任务协议有周期心跳/CRC/序号，但无线实测和整机任务接入未完成。新增传感器驱动在src/sensors；实际PWM除明确台架变体外保持零。
