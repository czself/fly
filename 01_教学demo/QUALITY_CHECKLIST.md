# 每课验收要求

- README 讲清学习目标、输入来源、引脚/供电、运行命令、预期结果和练习。
- 独立环境只编译一个 main；课程编号与 README/CSV/环境一致。
- 编译通过；涉及控制/输出门控的逻辑还要检查超时、丢包、无效值和边界。
- 默认输出停转；软件演示的物理 PWM 为 0。实际电机实验需拆桨，且验证超时/松手/复位时输出。
- CSV 列数、顺序、单位与代码相符；模板数据初始均为 0，采集记录单独保存。
- 命令有效不等于无线链路有效，读取成功不等于测量准确；必须明确每个标志的含义。
- 主机测试、模型运行、编译、烧录、实机连续数据和机械响应分别记录，未验证项不能标成通过。
- PID/混控坐标与符号有说明。真实电机位置/旋向/安装轴变换未确认时，虚拟混控不能接到 M 口。
